Layouts & Card Skins

Project Collection supports multiple layout engines and card skins.

Layouts

  • Grid — equal columns
  • List — stacked rows
  • Masonry — staggered heights
  • Slider — Swiper-powered carousel (bundled locally)

Card skins

Skins include: standard, overlay, minimal, caption, lift, index, split, and frame.

Motion for collections uses bundled anime.js. Slider uses bundled Swiper. Optional ambient 3D uses bundled Three.js when enabled in Settings.
