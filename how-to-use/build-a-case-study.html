Build a Case Study

  1. Go to Vista Portfolio → Add New.
  2. Start blank or pick a Design Library case study.
  3. Set title, featured image, and meta (Client, Year, Role, Duration, URL).
  4. Assign Categories / Services / Industries / Tags.
  5. Build the page with patterns (Hero, Overview, Results & Metrics) or your own blocks.
  6. Publish.
