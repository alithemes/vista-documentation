Reuse a Saved Layout

  1. Create a Saved Layout with your preferred Filter + Collection.
  2. Copy [vista_layout id="ID"].
  3. Paste into a Classic Editor field, a Shortcode block, or a builder shortcode widget — or use the Saved Layout block / Elementor widget.
