Installation

  1. Upload the vista-portfolio folder to /wp-content/plugins/, or install from a ZIP on Plugins → Add New.
  2. Activate Vista Portfolio.
  3. Open Vista Portfolio → Getting Started in the WordPress admin.
  4. If project URLs 404, visit Settings → Permalinks and click Save (no changes needed) to flush rewrite rules.

After activation you can create projects, browse the Design Library, and configure URLs under Vista Portfolio → Settings.
