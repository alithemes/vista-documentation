System Requirements

Vista Portfolio Free is a WordPress plugin for structured projects and portfolio collections.

Requirements

ComponentMinimum
WordPress6.7 or newer
PHP8.1 or newer
Browser (admin)Current Chrome, Firefox, Safari, or Edge
Block editor (Gutenberg) is required for Vista blocks and case-study patterns. Page builders can embed Saved Layouts via shortcode or Elementor widgets.
