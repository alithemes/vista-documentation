Project Collection

Block name: vista-portfolio/project-collection.

Queries vista_project posts and renders them with your chosen layout and skin.

  • Layout: grid, list, masonry, slider
  • Columns, gap, per page, order
  • Featured-only filter
  • Pagination / prev-next for slider
  • Card skin

Pair with Project Filter on the same page for taxonomy filtering.
