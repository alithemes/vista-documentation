Tools & Status

Open Vista Portfolio → Settings and switch to Tools & Status.

  • System status — environment checks useful for support.
  • Regenerate assets — rebuild front-end asset caches when needed.
  • Debug logging — enable temporary diagnostics.
  • System report — copy a text report for troubleshooting.
  • Import Demo — seed sample taxonomies and up to 10 demo projects (draft option available). Safe to re-run; does not overwrite existing matching content unnecessarily.

See also Import Demo Content.
